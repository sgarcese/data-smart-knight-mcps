# Repository Workflow Instructions

This repository uses a branch-first feature workflow.

- Create a dedicated branch for every major feature or sizable scope of work.
- Keep commits small, focused, and tied to a single piece of functionality.
- Add or update documentation before merging feature branches.
- Include documentation and usage notes in the same branch or PR when introducing new features.
- Prefer branch names like `feature/<short-description>` or `docs/<short-description>`.

> Do not merge a feature branch until its behavior is implemented, reviewed, and the relevant documentation has been added or updated.
